# なかまわけ（MieeL）

カードを指でスライドして「なかまの はこ」に入れる、仲間分け・分類の学習アプリです。iPad の全画面アプリとして使えます（Safari の「共有 → ホーム画面に追加」）。特別支援教育（知的障害特別支援学校など）向けです。

## あそびかた（3つのモード）
- 🧺 **なかまわけ**：カードを 2〜4この はこに わける
- 🎯 **あつめよう**：「くだもの」など ひとつの なかまだけを あつめる（ほかの カードは のこす）
- 🙅 **なかまはずれ**：ならんだ カードの なかから、ひとつだけ ちがうものを はこに いれる

カードは 指で スライドして はこへ。タップで えらんで → はこを タップ でも うごかせます。

## テーマ（43しゅるい＋じぶんで つくる）
- **いろ・かたち**：いろ（4しょく／10しょく）、ものの いろ、かたち、ものの かたち、おおきさ
- **たべもの**：くだもの と やさい、3しょく（あか・きいろ・みどり）、しょくじの なかま（しゅしょく・おかず・のみもの・おやつ）、あたたかい・つめたい、たべもの？、どこで とれる？、おやつ と やさい
- **いきもの**：どうぶつ と とり、どうぶつ・とり・うみ・むし、りく・うみ・そら、ペット・ぼくじょう・どうぶつえん、あしは なんぼん？、いきもの？ もの？、おおきい／ちいさい どうぶつ
- **のりもの・もの**：のりもの と どうぶつ、りく・そら・うみの のりもの、はたらく くるま、タイヤは いくつ？、きるもの・はくもの・かぶるもの・つけるもの、どこで つかう？、がっき・スポーツ・ぶんぼうぐ、そとあそび・へやあそび、でんきを つかう？、かたい・やわらかい
- **くらし・きせつ**：きせつ、てんき と もちもの、あつい ひ・さむい ひ、あさ・ひる・よる、しごと と どうぐ、きもちの かお、なつの ふく・ふゆの ふく
- **ことば・かず**：はじめの おと（あいうえお／かきくけこ）、もじの しゅるい（ひらがな・カタカナ・すうじ・アルファベット）、おなじ え、ことば と え、かず（いくつ？）

カードは 全部で 約860まい。はこが 多い テーマ（いろ など）は、毎回 ちがう 組み合わせが 出ます。

## 先生用せってい（右上の ⚙️ を 1.5秒 ながおし／Shift＋S）
- モード、カードの まいすう（4〜16）、はこの かず（おまかせ・2〜4）、だしかた（ぜんぶ／1まいずつ）、くりかえし
- なかまはずれ：ならべる カードの かず、もんだいの かず
- はこの しるし（え と ことば／ことばだけ／えだけ）、カードの なまえ、カードの おおきさ
- ヒント：まちがえたら ただしい はこが ひかる（なし／2かい／1かい／いつも＝まちがえない）
- タップ操作、よみあげ、こうかおん、おとの おおきさ、よみあげの はやさ、えんしゅつを ひかえめに
- **じぶんで つくる**：テーマの なまえ・はこ（2〜4こ）・いろ・カード（えもじ／もじ／**写真**）を つくれます
- きろく（CSV）、バックアップ（べつの iPad へ うつす）
